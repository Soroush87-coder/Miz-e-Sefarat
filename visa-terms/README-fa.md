# راهنمای نصب فرم تأیید شرایط خدمات ویزا (Travel Market)

فقط یک فایل دارید: `index.php`. بقیه کارها را خود فایل انجام می‌دهد.

## ۱. آپلود
1. در File Manager هاست، داخل `public_html` یک پوشه بسازید، مثلاً `terms`.
2. فایل `index.php` را داخل همان پوشه آپلود کنید.
3. لینک مشتری می‌شود: `https://دامنه-شما/terms/`
4. SSL (HTTPS) باید در پنل هاست روشن باشد.

## ۲. تنظیمات (فقط بالای فایل، بخش SETTINGS)
فایل را در File Manager با Edit باز کنید و فقط این مقادیر را پر کنید. رمزها را برای کسی نفرستید. این مقادیر فقط روی سرور می‌مانند و به مرورگر نمی‌رسند.

| تنظیم | چه چیزی بگذارید |
|---|---|
| `anthropic_api_key` | کلید Claude از console.anthropic.com → API Keys (با `sk-ant-` شروع می‌شود). برای حساب، اعتبار (Billing) فعال کنید. |
| `smtp_host` | آدرس SMTP ایمیل هاست، مثلاً `smtp.hostinger.com` |
| `smtp_port` / `smtp_secure` | معمولاً `465` و `'ssl'`؛ اگر کار نکرد `587` و `'tls'` |
| `smtp_user` / `smtp_pass` | آدرس کامل صندوق ایمیل و رمز همان صندوق |
| `mail_from` | همان آدرس `smtp_user` |
| `company_email` | ایمیلی که توافق‌نامه‌های امضاشده به آن ارسال می‌شود |
| `private_dir` | خالی بگذارید (خودکار، بیرون از `public_html`) |
| `keep_minutes` | مدت نگهداری موقت فایل‌ها روی سایت (پیش‌فرض ۱۲۰ دقیقه) |

## ۳. اولین باز کردن لینک
- بار اول، فایل پوشه خصوصی `travel-market-private` را **کنار** `public_html` می‌سازد (نه داخل آن) و کتابخانه‌های PDF (TCPDF) و ایمیل (PHPMailer) را با نسخه ثابت از GitHub دانلود و با هش SHA-256 بررسی می‌کند. چند ثانیه طول می‌کشد.
- اگر چیزی کم باشد، به‌جای فرم صفحه «راه‌اندازی کامل نیست» با فهرست موارد ناقص نمایش داده می‌شود. فرم تا رفع همه موارد کار نمی‌کند و هیچ فایل حساسی عمومی نمی‌شود.
- اگر هاست اجازه ساخت پوشه بیرون از `public_html` را نمی‌دهد، در File Manager پوشه‌ای کنار `public_html` بسازید و مسیر کامل آن را در `private_dir` بنویسید.

## ۴. یک آزمایش کامل
یک بار خودتان لینک را با گوشی باز کنید: کارت را اسکن کنید، امضا کنید، PDF را دانلود کنید و ببینید ایمیل به `company_email` رسیده است.

## ۵. نگهداری و پاک‌سازی
- عکس کارت هیچ‌وقت روی سرور ذخیره نمی‌شود: پس از خوانده‌شدن فوراً پاک می‌شود و داخل PDF هم نیست.
- PDF و اطلاعات جلسه پس از `keep_minutes` خودکار پاک می‌شوند. پاک‌سازی هنگام بازدیدهای بعدی سایت انجام می‌شود؛ اگر سایت بازدید نداشته باشد، فایل‌ها تا بازدید بعدی می‌مانند. برای پاک‌سازی دقیق‌تر، در Cron Jobs هاست هر ساعت این را اجرا کنید:
  `php /home/USER/public_html/terms/index.php cleanup`
- **مهم:** پس از پاک‌شدن، بازیابی از سایت ممکن نیست. نسخه ایمیلی را در صندوق شرکت نگه دارید.
- «ارسال شد» یعنی سرور ایمیل پیام را پذیرفته است، نه اینکه حتماً به صندوق رسیده باشد. اگر ایمیلی نرسید، پوشه Spam را ببینید.

## ۶. نکات
- اسکن کارت فقط برای پرکردن مشخصات است و احراز هویت رسمی نیست.
- شماره موبایل و ایمیل مشتری تأیید نمی‌شوند (همین در PDF نوشته شده است).
- برای تغییر متن شرایط، آرایه `$TERMS` را ویرایش کنید و `TERMS_VERSION` را عوض کنید.
- اگر فایل را با نسخه جدید جایگزین کردید، تنظیمات بالای فایل را دوباره پر کنید.
